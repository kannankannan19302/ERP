# Micro-Agent 1: Authentication & User Management

## Task Description
Implement the authentication system and user management functionality for the AgriERP system.

## Directory Context
- Backend authentication code should be placed in `/workspace/ERP/backend/src/modules/auth`
- Frontend authentication code should be placed in `/workspace/ERP/frontend/src/pages/auth`

## Requirements

### Backend
1. Implement JWT authentication controllers
2. Create user registration and login endpoints
3. Add password reset functionality
4. Implement role-based access control

### Frontend
1. Create login/registration pages
2. Implement authentication state management
3. Create user profile and settings pages

## Implementation Guidelines
- Follow the existing architecture and coding patterns
- Ensure proper validation and error handling
- Write tests for all implemented functionality
- Use the existing models (User, Role) for authentication
- Implement proper security measures (password hashing, token validation)

## Deliverables
1. Complete backend authentication module with controllers, routes, and validators
2. Complete frontend authentication pages and state management
3. Tests for all implemented functionality
